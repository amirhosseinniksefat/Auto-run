# Auto run — پلتفرم خودکار فروارد پیام از کانال‌های تلگرام

پلتفرم پیشرفته تحت وب جهت دریافت خودکار پست‌های جدید از کانال‌های عمومی تلگرام، ویرایش و بازنویسی هوشمند متن و انتشار در کانال مقصد به وسیله ربات تلگرام.

---

## ⚡ آپدیت و بروزرسانی کدها در ترموکس (Termux)

برای دریافت آخرین تغییرات و کدهای پروژه از گیت‌هاب در ترموکس مراحل زیر را انجام دهید:

### ۱. ورود به پوشه پروژه در ترموکس
```bash
cd REPOSITORY_NAME
```
*(به جای `REPOSITORY_NAME` نام پوشه کپی‌شده خود را وارد کنید)*

### ۲. دریافت آخرین تغییرات از گیت‌هاب
```bash
git pull origin main
```
*(یا اگر برنچ شما master است: `git pull origin master` یا کلاً `git pull`)*

### ۳. نصب/بروزرسانی پکیج‌های احتمالی جدید
```bash
npm install
```

### ۴. اجرای مجدد برنامه
```bash
npm run dev
```

---

## 📱 راهنامی اجرای اولیه روی ترموکس (Termux - اندروید)

### ۱. نصب پیش‌نیازها
```bash
pkg update && pkg upgrade -y
pkg install nodejs-lts git python make clang -y
```

### ۲. کلون کردن پروژه
```bash
git clone https://github.com/USERNAME/REPOSITORY_NAME.git
cd REPOSITORY_NAME
```

### ۳. نصب پکیج‌ها و اجرا
```bash
npm install
npm run dev
```

## ⚙️ امکانات بخش تنظیمات پیشرفته و فیلترها (Advanced Settings)

1. **فیلتر محتوای قابل ارسال:**
   - همه محتواها (متن و رسانه)
   - فقط متن‌ها
   - متن و عکس
   - متن و ویدیو

2. **تغییر و بازنویسی متن پیام:**
   - بدون تغییر (ارسال عین متن اصلی)
   - بازنویسی هوشمند با هوش مصنوعی (Gemini API) با دستور دلخواه
   - جایگزینی سفارشی کلمات و عبارت‌ها (Find & Replace)

3. **حذف و پاکسازی آیدی‌ها و لینک‌های مبدأ:**
   - حذف خودکار تمام لینک‌ها، منشن‌ها و آیدی‌های مربوط به کانال مبدأ
   - پاکسازی کلی تمام هشتگ‌ها (#) و لینک‌های وب

4. **افزودن امضا یا تگ اختصاصی به انتهای پیام:**
   - درج خودکار واترمارک، لینک کانال مقصد یا امضای برند شما زیر تمام پست‌ها
